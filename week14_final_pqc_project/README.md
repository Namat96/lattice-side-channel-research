# Week 14 — Final PQC Side-Channel Research Review

This is the final week of the project. It brings together the mathematical, implementation, side-channel, and performance topics studied throughout the previous weeks.

The purpose is to organize the project results into a final research-style summary and record the main lessons, limitations, and possible future work.

## Project focus

The project studied side-channel leakage and approximate-hint LWE secret recovery in lattice-based cryptography, followed by lattice, Ring-LWE, Module-LWE, ML-KEM, ML-DSA, performance, and implementation-security experiments.

## Objectives

- Summarize the complete 14-week research progression.
- Record the main findings from the experiments.
- Separate mathematical security from implementation security.
- Document limitations of the toy experiments.
- Identify possible future research directions.
- Perform a final project structure check.

## Files

- `project_overview.md` — complete project overview.
- `research_findings.md` — main findings from the project.
- `limitations_and_future_work.md` — limitations and possible next steps.
- `final_check.py` — simple final checklist.
- `final_report.md` — final research-style report.

The code in this week is a project check, not a cryptographic implementation.
