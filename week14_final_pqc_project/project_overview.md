# Project Overview

## Topic

Side-channel leakage and approximate-hint LWE secret recovery in lattice-based cryptography.

## Progression

1. Research foundation
2. Leakage models
3. Side-channel basics
4. LWE secret recovery
5. Leakage correlation
6. Lattice cryptography fundamentals
7. Lattice reduction and LLL
8. Ring-LWE and Module-LWE
9. Kyber / ML-KEM
10. ML-DSA / Dilithium
11. Side-channel analysis of lattice operations
12. PQC performance and implementation analysis
13. PQC security review and threat analysis
14. Final project review

## Main tools

- Python
- NumPy
- VS Code
- Git and GitHub

## Project style

The experiments use small educational examples to understand the underlying ideas. They are not intended to reproduce production cryptographic implementations.
