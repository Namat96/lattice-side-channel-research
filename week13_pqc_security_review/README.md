# Week 13 — PQC Security Review and Threat Analysis

This week reviews the security lessons from the project and connects them with the main threat models studied earlier.

The work focuses on identifying possible implementation weaknesses, separating mathematical security from implementation security, and organizing practical mitigations.

These are educational review exercises, not attacks against real cryptographic systems.

## Objectives

- Review the main threats studied during the project.
- Distinguish mathematical attacks from implementation side channels.
- Build a simple threat-to-mitigation table.
- Study why constant-time implementation matters.
- Prepare security observations for the final project report.

## Files

- `threat_matrix.py` — prints a simple threat and mitigation matrix.
- `attack_surface.py` — organizes possible attack surfaces in a toy PQC implementation.
- `mitigation_checklist.py` — checks a basic implementation-security checklist.
- `security_summary.md` — Week 13 research notes.
